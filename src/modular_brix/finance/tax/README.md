# tax (C11)

Dated tax rates, prepared-then-validated VAT returns and explained adjustments.

- The rate at any historical date stays retrievable; collected comes from issued invoices, deductible from validated supplier invoices and approved expenses, so the return reconciles to sources; a validated return is frozen; adjustments always carry a reason.
- Limits: exigibility (débits/encaissements), exemption reasons and pre-filled declarations remain to implement.

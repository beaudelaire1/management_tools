# Modular Brix - Lot 0

Neutral modular Django foundation for management, finance, accounting, and steering systems.

## Scope

This repository currently delivers Lot 0 from the specification:

- reproducible package setup
- Django 5.2 LTS baseline
- modular foundation app skeleton
- initial organization domain model and migration
- test scaffold and CI-ready local commands

## Quick start

1. Create and activate a Python 3.13 virtual environment.
2. Install package in editable mode with dev dependencies.
3. Run migrations.
4. Run tests.

## Compliance note

This codebase is neutral and contains no client branding or studio-specific runtime marks.
Regulatory compliance for production must be validated per client context.
